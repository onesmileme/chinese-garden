# 古文乐园家长设置设计

> 状态：已批准
> 日期：2026-09-15
> 范围：Playground 与 Taro 小程序的家长中心

## 1. 目标

在现有“家长中心”内增加系统设置，不新增首页入口。首页右上角齿轮继续作为家长入口，并将门禁时长从长按 3 秒调整为长按 2 秒。

本次设计解决以下问题：

- 家长可在同一页面查看学习状态、成长记录和系统设置。
- 两端使用相同的设置字段、默认值和文案。
- 设置修改即时生效并持久化。
- 清除学习记录等风险操作有明确保护。
- 设置状态与学习领域状态隔离，避免偏好变更影响学习契约。

## 2. 页面结构

采用已确认的“单页分组”方案。页面标题保持“家长中心”，由上到下排列：

1. 学习状态
   - 能力探索
   - 今日进度
2. 成长记录
   - 当前等级
   - 累计成长值
   - 已完成天数
3. 声音与体验
   - 背景音乐
   - 答题音效
   - 震动反馈
   - 护眼模式
4. 提醒与数据
   - 每日提醒
   - 清除学习记录

页面沿用当前宣纸背景、白色内容面板和古典配色。每个设置行的最小点击高度为 64px；二元设置使用开关，不使用文字按钮。页面不增加标签页或二级设置页。

成长记录中的展示文案由“累计经验 / XP”调整为“累计成长值”，内部 `lifetimeXp`、`xpAwarded` 等字段及事件契约保持不变。

## 3. 入口与门禁

- 首页右上角继续显示齿轮图标。
- 齿轮的无障碍名称保持“长按进入家长中心”。
- 长按持续时间统一为 2,000ms。
- 按住时显示环形进度反馈；达到 2 秒后进入家长中心。
- 提前松开、指针移出、触摸取消或组件卸载时取消计时并清空进度。
- 不新增直接点击进入方式，避免儿童误入设置。

Playground 与小程序当前分别维护 `ParentGate`，两端采用同一时长常量和相同交互语义。

## 4. 设置模型

设置模型位于应用层，与学习会话状态分离：

```ts
interface GuardianSettings {
  backgroundMusicEnabled: boolean;
  answerSoundEnabled: boolean;
  hapticsEnabled: boolean;
  eyeProtectionEnabled: boolean;
  dailyReminder: {
    enabled: boolean;
    time: string; // 24 小时制 HH:mm
  };
}
```

默认值：

| 设置 | 默认值 |
|---|---|
| 背景音乐 | 开启 |
| 答题音效 | 开启 |
| 震动反馈 | 开启 |
| 护眼模式 | 关闭 |
| 每日提醒 | 关闭 |
| 提醒时间 | 20:00 |

设置使用带版本号的独立存储键。读取时执行结构校验；缺失、版本过旧或字段非法时回退到默认值，不返回部分损坏状态。

## 5. 交互行为

### 5.1 即时保存

设置项修改后立即写入本地存储，不提供额外“保存”按钮。写入成功后通知订阅者，由页面和平台能力适配器应用新值。

写入失败时：

- 恢复修改前的值。
- 在设置区域显示“设置保存失败，请重试”。
- 不影响学习状态和答题流程。

### 5.2 声音、震动与护眼模式

- 背景音乐和答题音效分别控制对应音频能力，不互相覆盖。
- 震动反馈关闭后，答题结果和关键操作不触发触觉反馈。
- 护眼模式切换全局低亮度、低对比度暖色主题，同时保证文字对比度满足可读性要求。
- 当前仓库尚无背景音乐资源；首版不新增音乐素材，只提供设置状态和能力接口。不存在对应能力时不得假装播放。

### 5.3 每日提醒

- 行内同时展示开关和提醒时间。
- 开启后可点击时间值，通过平台时间选择器修改，使用 24 小时制。
- 首次开启时由平台提醒能力请求授权。
- 用户拒绝授权或平台不支持时恢复关闭，并显示明确原因。
- Playground 提供可测试的模拟适配器。
- 小程序真实提醒依赖订阅消息模板和服务端调度配置；在这些配置就绪前，能力适配器返回“不支持”，不展示虚假的开启状态。

### 5.4 清除学习记录

“清除学习记录”使用危险操作样式。点击后打开确认对话框，默认焦点停留在“取消”；确认文案需说明数据不可恢复。

确认后清除：

- 能力探索状态与进行中的能力探索；
- 今日学习会话与结算记录；
- 等级、累计成长值和已完成天数；
- 进行中的亲子挑战、挑战来源与历史结果；
- 尚未同步的学习事件，避免清除后旧记录再次上传。

以下内容保留：

- 家长设置；
- 已下载内容包与内容版本缓存；
- 登录身份和认证会话。

清除成功后刷新家长中心数据并返回初始状态。任一必要存储删除失败时显示错误，不将内存状态伪装为已清除。

## 6. 模块边界

### `@cc/application`

- 定义 `GuardianSettings`、默认值及校验。
- 提供设置存储、更新和订阅接口。
- 定义平台无关的 `ReminderPort`、`AudioPreferencePort`、`HapticsPreferencePort` 和 `ThemePreferencePort`。
- 提供原子化的学习记录清除用例。

### Playground

- 使用浏览器存储实现设置仓储。
- 使用提醒模拟适配器，便于预览授权成功、拒绝和不支持状态。
- 渲染 Web 控件并响应设置订阅。

### Taro 小程序

- 使用现有 Taro 存储适配器持久化设置。
- 通过 Taro 能力实现震动、主题和时间选择。
- 通过订阅消息适配器接入提醒授权；缺少模板或服务端配置时返回不支持。

### 页面组件

两端页面保持薄适配，设置项顺序、标题、说明、默认值和危险操作语义来自共享展示模型。平台视图只负责渲染原生控件和调用应用层命令。

## 7. 错误与边界处理

- 非法提醒时间回退到 `20:00`。
- 存储内容损坏时使用完整默认设置并覆盖损坏快照。
- 快速连续切换同一开关时串行化写入，以最后一次用户选择为准。
- 页面卸载后不得继续更新状态或触发门禁跳转。
- 权限拒绝不循环弹窗；仅在用户再次主动开启提醒时重试。
- 清除学习记录与进行中的持久化写入必须串行，避免旧会话在清除后被重新写回。

## 8. 测试策略

应用层逻辑维持 100% Vitest 覆盖率，重点覆盖：

- 默认设置与合法快照恢复；
- 损坏、缺字段和旧版本快照回退；
- 设置更新、订阅、串行写入和失败回滚；
- 提醒授权成功、拒绝及平台不支持；
- 学习记录清除范围和保留范围；
- 清除失败时内存与持久化状态一致。

两端组件测试覆盖：

- 四个体验开关、每日提醒和清除入口完整展示；
- “累计成长值”文案；
- 设置修改后刷新仍可恢复；
- 清除确认的取消与确认路径；
- `ParentGate` 按住 2 秒成功、提前松开、取消触摸和卸载清理；
- 键盘焦点、无障碍名称与 64px 点击区域。

最终执行前端完整 `typecheck` 与测试套件。

## 9. 验收标准

1. 首页齿轮长按不足 2 秒不会跳转，达到 2 秒进入家长中心。
2. 家长中心按既定顺序展示学习数据与六项设置。
3. 所有可用设置即时保存，重新进入页面后保持原值。
4. 不支持的系统能力明确显示原因，不产生虚假成功状态。
5. 清除学习记录必须二次确认，且不清除家长设置、身份和内容缓存。
6. Playground 与小程序的字段、默认值、文案和交互语义一致。
7. 内部 XP 字段和事件契约不变，界面统一显示“成长值”。
8. 新增逻辑达到项目规定的测试覆盖率，完整类型检查和测试通过。

## 10. 非目标

- 本次不新增背景音乐或答题音效素材。
- 本次不建设小程序订阅消息模板、消息调度后台或运营配置。
- 本次不新增家长账号、PIN 码或独立身份认证。
- 本次不重构学习等级、成长值计算或内容解锁规则。
